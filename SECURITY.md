# Sicherheitslücken melden

Bitte **nicht als öffentliches Issue**. Nutze auf GitHub den Reiter **Security** und dort **Report a vulnerability**. Die
Meldung bleibt vertraulich, bis es eine Behebung gibt.

Schreib hinein, was passiert, wie man es auslöst und welche Fassung betroffen ist (unten links auf der Seite). Keine echten
Schlüssel, Passwörter oder privaten Daten mitschicken.

| Besonders wichtig | Beispiel |
|---|---|
| Zugriff ohne Schlüssel | Daten lesen oder ändern ohne Anmeldung, Geräte-Schlüssel darf mehr als melden |
| Fremder Code | Eine Seite, Notiz oder Datei bringt Skripte in die Oberfläche oder Befehle auf den Rechner |
| Datenverlust | Aufräum-Werkzeuge entfernen etwas, das sich nicht neu erzeugt |
| Agenten steuern | Text von außen bringt die Agenten dazu, gegen `REGELN.md` zu handeln |

Geprüft wird nur die neueste Fassung auf `main`. Das Projekt wird in der Freizeit gepflegt, eine feste Antwortzeit gibt es
nicht.
